## Standards & Guidelines

- [How to Meet WCAG (Quick Reference)](https://www.w3.org/WAI/WCAG22/quickref/) - The W3C quick reference for the Web Content Accessibility Guidelines, filterable by level.
- [W3C Web Accessibility Initiative (WAI)](https://www.w3.org/WAI/) - Standards, strategies, and resources from the W3C.
- [WebAIM](https://webaim.org/) - Accessibility training and resources, including the annual screen reader user surveys.

## Testing & Auditing Tools

- [axe-core](https://github.com/dequelabs/axe-core) - The leading open-source accessibility testing engine; runs automated checks in browsers and CI.
- [WAVE](https://wave.webaim.org/) - Web accessibility evaluation tool that identifies errors and contrast issues directly in the browser.
- [Pa11y](https://pa11y.org/) - Automated accessibility testing for continuous integration, with a dashboard for trend tracking.
- [Axe DevTools](https://www.deque.com/axe/) - Deque's browser extension and developer tooling built on axe-core.

## Voice Dictation & Voice Control

- [Apple Voice Control (Mac)](https://support.apple.com/guide/accessibility-mac/use-voice-control-commands-mh40719/mac) - Dictate text and control macOS entirely by voice.
- [Apple Voice Control (iPhone/iPad)](https://support.apple.com/en-us/111778) - Voice-based navigation and dictation for iOS and iPadOS.
- [Google Voice Access (Android)](https://support.google.com/accessibility/android/answer/6151848) - Spoken commands to open apps, navigate, and edit text on Android.
- [Siri](https://www.apple.com/siri/) - Apple's voice assistant for hands-free calls, messages, and app control on iPhone, iPad, and Mac.
